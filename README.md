# Staywell hotels

A frontend-only React + Redux hotel manager. Hotel records and uploaded photos are stored in this browser with local storage. The supplied hotel photos are used for the starter listings. No server or database is required.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install` in this folder.
3. Run `npm run dev` and open the local URL shown in the terminal.

Changes stay in the current browser; clearing its site data resets the starter hotels. The UI uses no animations or transitions.
